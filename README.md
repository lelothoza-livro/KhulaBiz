 # KhulaBiz - AI Business Assistant for South Africa

**Live Demo:** https://khulabiz.base44.app
**GitHub:** https://github.com/lelothoza-livro/KhulaBiz
**Built for:** FNB Hackathon - Township Economy

### Problem
Small township businesses struggle with bookkeeping, marketing, and growth.

### Solution
KhulaBiz is a personal AI business assistant that helps small businesses in South Africa grow, manage finances, and generate professional marketing content.

### Features
- Transaction tracking & finance dashboard
- AI marketing content generator
- Business analytics
- Secure user management
- Mobile-first design

### Tech Stack
- Base44 (React + Tailwind + Managed Backend)
- Base44 Cloud Hosting
- GitHub for version control

### How to Run
Visit: https://khulabiz.base44.app

No local setup needed - hosted on Base44.
